Listado de 102 Etiquetas HTML

Número Nombre de la Etiqueta Descripción Ejemplo de Uso Elemento Adicional
1 <a> Define un hipervínculo. <a href="https://www.google.com">Ir a Google</a> Puede usar target="_blank" para abrir en nueva pestaña.
2 <p> Define un párrafo de texto. <p>Este es un párrafo</p> Puede contener elementos en línea como <strong> o <em>.
3 <img> Incrusta una imagen en la página. <img src="imagen.jpg" alt="Descripción"> El atributo alt es obligatorio para accesibilidad.
